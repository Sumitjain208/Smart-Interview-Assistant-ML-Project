# 🎤 AI Smart Interview Assistant

An AI-powered Interview Preparation Assistant built using Machine Learning, NLP, Speech Recognition, and Computer Vision.

This project simulates a real interview environment where the system:
- asks interview questions dynamically
- converts speech to text
- analyzes candidate answers
- evaluates confidence level
- performs webcam attention analysis
- provides AI-generated interview feedback


# 🚀 Features

✅ Dynamic Interview Questions  
✅ Speech-to-Text using SpeechRecognition  
✅ NLP-based Answer Evaluation  
✅ Sentiment Analysis  
✅ Voice Confidence Analysis  
✅ Webcam Attention Detection  
✅ Real-time AI Feedback  
✅ Interactive Streamlit Dashboard  
✅ Machine Learning Pipeline Architecture
